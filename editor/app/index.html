Encrypted Markdown Source Editor

Open any content/**/*.md.enc.json source, decrypt it only in this browser, edit the raw Markdown, and write back a fresh AES-256-GCM ciphertext.

No plaintext upload. The host only serves this editor. Selected encrypted files are read locally by the browser. PBKDF2, AES-GCM decryption/encryption and editing happen in browser memory. This app does not use localStorage, IndexedDB, a service worker, analytics, fetch/XHR, or remote scripts.

1. Open or create source

Current format: AES-256-GCM + PBKDF2-HMAC-SHA256. Legacy source files from the earlier Nmap-only repo can also be opened and are migrated to the generic source label when saved.

or drag a .md.enc.json file onto this panel

3. Edit raw Markdown

4. Re-encrypt

Every save generates a fresh 16-byte salt and 12-byte IV and uses 600,000 PBKDF2 iterations. For sources built by this repository, use the same password configured as CONTENT_PASSWORD.

Plaintext necessarily exists in browser/process memory while unlocked and can still be visible to memory scanners, swap/hibernation, screenshots, clipboard tools, or browser crash diagnostics.
